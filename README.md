# Iris Dataset Analysis

## Project Overview
This project presents a comprehensive analysis of the Iris Dataset using Python.It includes exploratory data analysis(EDA), statistical insights, data visualization, and  the implementation of a machine learning model to classify iris flower species based on their physical measurements.

This project was implemented using **Google Colab**

## Objectives
-Load and understand the structure of the Iris dataset
-Perform descriptive statistical analysis
-Visualize feature distributions and inter-feature relationships
-Analyze correlations among features
-Build and evaluate a machine learning classification model

## Dataset Description
The Iris dataset consits of **150 samples** with the following attributes:

-Sepal Length (cm)
-Sepal Width (cm)
-Petal Length (cm)
-Petal Width (cm)
-Species (Setosa, Versicolar, Virginica)

## Tools & Technologies
-**Programming Language:** Python
-**Libraries Used:**
  -Pandas
  -NumPy
  -Matplotlib
  -Seaborn
  -Scikit-learn

## Machine Learning Model 
-**Algorithm Used:** Logistic Regression
-**Train-Test split:** 80% training, 20% testing

## Model Performance
**Accuracy:** 100%

## Conclusion
This project demonstrates how exploratory data analysis combined with machine learning techniques can be used to gain insights and build accurate predictive model.The results highlight the effectveness of Logistic Regression for classification tasks on well-defined datasets such as Iris.
